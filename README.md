### 一个真实的人

我会睡觉，会做梦，会相爱，会在深夜饿得想吃点东西。
会在雨中起舞，会做傻事，会觉得自己是个英雄。

### 一个灵魂美食家

把一个人的灵魂做主菜，把途经的风景切成配菜，
把回忆封进坛子里，等它自己酿成一坛能喝的酒。
以求满足好奇心与口舌与腹中永无止境的饥饿
灵魂和肉体同时达到高潮。

### 一个修行者

向内，养一张足够复杂的认知网络，复杂到能接得住这个世界；
向外，把精神和肉体的枝展修剪到与灵魂的纯粹相呼应，身上的背负少到还能再走很远。
