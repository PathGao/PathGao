### 真实智人类

我会睡觉，会做梦，会相爱，会在深夜饿得想吃点东西。  
会在雨中起舞，会做傻事，会觉得自己是个英雄。

### 贪婪美食家

把生命的灵魂燉做主菜，把途经的风景切成配菜，
把回忆封进坛子里，等它自己酿成一坛辛醇的琼浆。
口舌的朵盈，挑拨着无尽的饥饿与享乐，达到灵魂和肉体共同高潮。

### 永恒修行者

向内，养一张足够复杂的认知网络，复杂到能接得住整个世界。  
向外，把精神和肉体的枝展一节节修度，  
与灵魂的纯粹相呼应，轻装还能再走很远。
