兴奋地雨中起舞，故意做傻事，让自己相信自己是个英雄。

### 贪婪美食家

将生命的灵魂燉作主菜，把途经的风景切成配菜，  
收集回忆封进坛子里，等它自己酿成一坛辛醇的琼浆。  
口舌的朵颐，挑拨着无尽的饥饿与享乐，达到灵魂肉体的共同高潮。

轻装还能再走很远。
