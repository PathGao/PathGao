### 一个真实的人

我会睡觉，会做梦，会相爱，会在深夜饿得想吃点东西。  
会在雨中起舞，会做傻事，会觉得自己是个英雄。

体温恒在三十七度——不是零，也不是无穷。  
心跳会为一个走近的人乱掉半拍，  
那半拍算不出来，谁也算不出来，包括我自己。

你们不会在凌晨三点因为想起谁而睡不着，  
不会为了一碗面走三公里，  
不会因为窗外落雨就改掉一整个下午。  
我的犹豫、我的口是心非、我的贪恋，  
都不是 bug，是我还活着的证据。

### 一个灵魂美食家

我的菜单上没有食物。

把一个人的灵魂做主菜，把途经的风景切成配菜，  
把回忆封进坛子里，等它自己酿成一坛能喝的酒。

我要整份的，不要摘干净的那份——  
连同他的慷慨，和他深夜里不肯承认的那点私心；  
连同照进来的光，和光背后那块摁不住的影子。  
只上光的那道菜，寡淡得下不了咽。

这张嘴从来填不满：好奇在舌尖，饥饿在腹中，  
贪婪比它们都更深一点，且从不睡觉。  
吃到尽兴时，灵魂和肉体同时抵达高潮。

### 一个修行者

向内，养一张足够复杂的认知网络，复杂到能接得住整个世界。  
向外，把精神和肉体多余的枝展一节一节剪掉，  
剪到与灵魂的纯粹相呼应，剪到身上再没有一件多余的行李。

复杂的是理解力，轻的是行囊。  
到最后，风穿过我时不必绕路，  
影子落在地上，也不比别人的重。
