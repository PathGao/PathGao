# 画面样式规范

回答“画面长什么样”：选哪套风格、叠加图形怎么做、颜色字体和动效的取值。做的步骤见各 workflows，验收与交付见[制作规范](制作规范.md)，组件用法见各组件库 README。规则只在本文件维护，其他文档链接到这里。依据都来自[模仿对象](模仿对象/说明.md)里的拆解与调研（Redknot-乔红、影视飓风、柱子哥等），结论变化时先更新证据文档，再改本文件。

## Y1 通用原则

适用于所有画面类型。依据：[高级感一手调研](模仿对象/高级感一手调研.md)、[科学动画与实拍讲解对标](模仿对象/科学动画与实拍讲解对标.md)。

- 做减法：少字号、少颜色、少运动、多停顿。每加一个元素都要说明它表达什么信息。
- 看得清优先于效果：文字在手机观看尺寸下可读，图形不遮住正在讲的那块画面。
- 念到才出：图形和旁白同时出现，不提前、不滞后。
- 每屏一个焦点：同一时刻只给一处上强调色或做强调动作，其余退为白或淡白。
- 信息变了才动：入场后静止。背景不动，不加循环脉冲、持续转动和持续漂移。
- 信息尽量在画面里发生：能用素材本身的操作、变色、拆分讲清的，不另贴图形。图形只负责命名、指认和强调。
- 融入画面：图形的颜色、粗细跟着底下的画面走，不为了“有风格”而突兀。

## Y2 禁用项

- 胶片颗粒、暗角、扫描线、持续镜头漂移、装饰性斜光束。科普讲解没有年代动机，会显得古早（v2 被否决的原因）。
- 不表示真实量的刻度、导轨、计数、进度条；随机生成的数字或字符填充。
- 辉光、泛光、镜头光晕。
- 无信息的转场：小节内直接硬切，转场只标记章节。
- 弹跳、弹性缓动（印章落下等单个事件除外）。

## Y3 按画面类型选风格

| 画面类型 | 风格 | 用什么 | 状态 |
| --- | --- | --- | --- |
| 纯生成科技画面（整段由程序画出） | 深紫底、霓虹色、斜切硬线条（Y5） | [画面组件库](asset/motion/README.md) v3 | 已定稿 |
| 录屏、电脑画面、截图 | 细线细字叠加（Y4、Y4a） | [叠加层组件](asset/overlay/README.md) | 制作中 |
| 真人实拍、AI 生成写实画面 | 融入实拍的叠加（Y4、Y4b） | 叠加层组件可用部分；遮挡和跟踪需另配工具 | 规则已定，工具待定 |
| 科学动画（原理示意、结构、过程） | 待对标拆完再定 | 待定 | 拆解中 |

- 风格不混用：深紫霓虹组件不叠在真实画面上，叠加层不进纯生成科技画面。
- 组件库 v3 里的 `highlight`、`callout` 只用于嵌在科技画面里的截图；整段录屏或实拍改用叠加层。
- 截图举证类视频：纯生成科技画面里嵌入的整张证据截图用组件库 v3.1 的 `evidence-shot`（自带硬阴影边框、按关键句裁切和高亮），属于组件库画面，不算叠加层。关键句坐标用 `tools/ocr-locate` 取，不手量。

## Y4 叠加通用规则（录屏、截图、实拍、AI 写实画面）

依据：Redknot-乔红与影视飓风拆解，见[对标文档](模仿对象/科学动画与实拍讲解对标.md)。

1. 信息尽量在画面里发生：能拍实物、用素材本身的操作讲清的，不另加图形；叠加层只做命名、指认和强调。
2. 不加底板、不压暗画面、不用品牌色。可读性靠放在画面里低细节的区域，加极淡投影。
3. 标题和大字放在画面空白处，不压住正在讲的内容。
4. 墨色从画面亮度决定：深色画面用白 `#F5F5F2`（加 `0 1px 3px rgba(0,0,0,.45)` 投影），浅色画面用近黑 `#141414`（不加投影）；一个镜头内只用一种。
5. 只在旁白念到关键词那一刻或硬切后第一拍出现；单次 2–6 秒，同屏不超过 3 个。
6. 超过“一个数字或一个词”的解释，硬切到纯色底的信息图或科学动画，不在真实画面上堆叠。

## Y4a 录屏、电脑画面、截图

依据：Redknot-乔红。

1. 只用细线细字：引线 2px，端点圆环直径 14px；手绘圈注 3px，两端略不闭合。
2. 等画面停稳再出标签（不在滚动、切换中途出）。录屏不额外放大，保持[产品录屏](workflows/原创讲解.md#产品录屏)的完整视野规则。
3. 强调色默认不用；确需区分时只用一处荧光绿 `#C0F800`。

| 项 | 取值 |
| --- | --- |
| 字体 | 苹方。概念标题中文 Semibold，英文斜体正常大小写；标签 Medium |
| 字号 | 概念标题 88px，英文副标 36px，标签 40px，全屏单字 360px（Light） |
| 动作 | 标题从 0.3 透明度淡入 0.5 秒；引线 0.35 秒画出后文字 0.25 秒淡入；圈注 0.3 秒画完；斜线分屏 0.35 秒扫过；全屏单字直接出现 |

## Y4b 真人实拍、AI 生成写实画面

依据：影视飓风四条视频拆解。

1. 用遮挡建立深度：关键词大字插在人物和手之间，或从人物背后出来，让前景挡住字。
2. 贴在表面：能铺在平面上的字，按平面透视铺上去，让实物压在字上，镜头动时字跟着平面走。
3. 跟踪锚定：物体上的数值标签钉在物体上，跟镜头一起动。
4. 字用粗黑体（苹方 Semibold），大字可加柔和发光并向下渐隐，和画面过渡。
5. 颜色常态白色；语义色最多一种并固定含义（概念、阈值、超标各一色，按期在项目说明里定）；也可取画面里物体的同色系。同屏不超过 2 色。
6. 地点、日期卡放左下，来源放左上，小字半透明，不进画面中心。
7. 访谈、情绪段不叠加任何图形；连续讲解段约每 30 秒留一段无图形。

制作限制：遮挡需要逐帧抠出人像或手，跟踪需要运动跟踪数据，HyperFrames 目前都不直接支持，需另选工具（如 AE，或 AI 抠像与跟踪）。工具未定前，实拍上先用 Y4 和 Y4b 第 4–7 条。

## Y5 纯生成科技画面（组件库 v3）

依据：用户 B站头像、[画面包装动效拆解](模仿对象/画面包装动效拆解.md)、[高级感一手调研](模仿对象/高级感一手调研.md)。

| 角色 | 颜色 | 用法 |
| --- | --- | --- |
| 底色 | 深紫 `#1A0A2E` / `#381559` / `#5A2D85` | 背景、卡片底 |
| 主色 | 橙 `#FD7102` | 章节色块、警示、对比推荐项、最终选择 |
| 强调 | 荧光绿 `#C0F800` | 当屏唯一焦点：重点数字、描边、当前项 |
| 点缀 | 荧光青 `#68F8D8` | 只用于截图上的标注（高亮扫描线、引线目标点） |
| 小标签 | 淡白 `rgba(245,242,250,.62)` | 英文小标、编号、次要说明 |

- 造型：直角和斜切角，不用圆角。
- 字号三档：大字（每屏一个）、正文 48px、小标签 24–26px 等宽全大写淡白。
- 光影：硬阴影统一右下深色 `#0B0414`。高光只在事件发生时出现（数字落定、印章落下）。
- 入场 0.2–0.4 秒，`power3.out` 或 `expo.out`，带斜向位移和轻微倾斜收正；错峰同组 0.03–0.06 秒、主副层级 0.1–0.2 秒、跟旁白逐条 0.35–0.6 秒；数字滚动 1.2 秒 `expo.out`。
- 组件不做退场动画，退场交给章节转场或下一个镜头硬切。

## Y6 字体

- 动画画面、封面和标题的中文用苹方，文件在 `asset/motion/fonts/`（HyperFrames 无头浏览器读不到系统字体，必须用文件）。
- 压制进视频的字幕（双语，以及原创仅中文字幕）用字幕预设里的思源黑体，字体和样式以[所选预设](制作规范.md#字幕与声音)为准。
- 禁止 Arial Unicode / Arial Unicode MS，包括中文回退字体（见 AGENTS.md）。

## Y7 常驻导航：章节进度条与日期游标

依据：2026-11-06 URXR 一期用户要求“进度条以后固定每期都有”“按时间顺序讲的内容给时序”，并选定常驻日期游标形式。

- 章节进度条每期原创视频必带，全程常驻画面底部（标签 994–1024 px，轨道 1030–1036 px），压到录屏、实拍或原片字幕等底部内容也保留，不为它加底框（用户 2026-11-06 定）。纯生成科技画面用组件库 `progress`，录屏和实拍用叠加层 `o-progress`，墨色按该镜头底边亮度选。章节卡出现时进度条可被章节卡色块遮住。
- 日期游标只用于按时间顺序讲述的章节，且只挂在嵌入纯生成科技画面的截图或截帧镜头上方（y 24–100 px），用组件库 `date-ruler`，每个镜头一个 slot，游标从上一镜头日期移到本镜头日期，0.3–0.4 秒后静止。满屏录屏和实拍保持原大小，不挂日期游标（用户 2026-11-06 定）。
- 两者都是导航，入场后静止，不加任何持续动效；画面主体内的强调仍只用一处。
- 常驻导航占用的上下边带，其他元素避开：截图和信息图内容在 150–906 px 内，字幕底边距画面底部 90 px。挂日期游标的镜头，`evidence-shot` 用 `by` 200、`bh` 600（不低于 192），否则高亮标签会压住游标日期。
