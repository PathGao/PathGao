# AI-Workspace

这是我和多个 AI 共同工作的地方。每个项目都有自己的目录，想做哪件事，就打开对应目录开始会话，不用在开聊之前先想一套复杂的项目管理。

```text
AI-Workspace/
├── 想法储备-真人管理/   留给自己整理想法
├── Code_Projects/      软件开发
├── Film_Creator/       视频制作
└── Skill_Share/        共用技能
```

我的管理习惯是干净、轻量、co-working、唯一事实来源和树状整理：东西放回所属目录，规则和当前状态各有一处准确信息，多个 AI 读同一份文件接着工作，不靠翻找一条越来越长的聊天记录。

每次会话尽量短，围绕一件事展开。需要接着做的内容留在项目文件里，再开新会话，减少无关上下文对准确率和速度的拖累。

这会是随时喜欢收拾一下桌子的人容易爱上的工作方式。打开简单，用完归位。所有积木和框架都是一点点搭起来，再拆掉、调整，在实际使用中迭代的。

拿去用时，让 AI 先读对应目录的 `AGENTS.md`，再按你的机器和任务补齐工具。这里分享目录骨架与管理约定，主要面向 macOS。
